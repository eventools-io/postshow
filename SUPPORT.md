# Postshow support

Choose the channel that matches the information in your request.

## Hosted Postshow, accounts, and billing

Email [support@eventools.io](mailto:support@eventools.io) for account access,
workspace administration, billing, hosted-runtime incidents, deletion or export
requests, and other matters that may contain private customer context.

Check [status.eventools.io](https://status.eventools.io) before reporting a hosted
service outage. Postshow does not publish a general support response-time guarantee;
an applicable order form may define separate support terms.

Do not place passwords, access tokens, API keys, connector secrets, private customer
records, payment-card data, or sensitive logs in email or a GitHub issue. Ask
support for a safer transfer method before you send a sensitive artifact.

## Open-source bugs

Use [GitHub Issues](https://github.com/eventools-io/postshow/issues) for a
reproducible bug in the web client, desktop client, CLI, MCP server, or shared engine
when the report can be public and contains no customer data or secrets.

Include the affected version or commit, operating system and Node version where
relevant, minimal reproduction steps, expected behavior, observed behavior, and
sanitized diagnostics. Search existing issues first.

This repository contains inspectable clients and a local runtime. It does not
provide a supported one-command replacement for Postshow's hosted control plane.
Support for a self-managed deployment requires a separate written agreement.

## Security vulnerabilities

Do not file a public issue. Follow [SECURITY.md](SECURITY.md) and email
[security@eventools.io](mailto:security@eventools.io).

## Contributions and feature requests

Use the repository's feature-request template for public product ideas. See
[CONTRIBUTING.md](CONTRIBUTING.md) before submitting code. Participation in the
project is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
